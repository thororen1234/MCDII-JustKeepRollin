BETTER BLUEPRINT LOADER
=======================

Loads blueprint mods for Minecraft Dungeons II!

Mods in your ~mods folder start automatically every time a level loads, with their mod info and settings pages. Use it as your only mod loader: loaders change the same game file, and only one of them can work.

MODS TAB
--------

Open the game's Settings and choose the Mods tab, or click MODS on the main menu. In game: Esc, Settings, Mods.

On the left are BetterBlueprintLoader and every mod it found. Choose one to see its page:
    Its name, version, author and description, from the mod.
    Whether it's running and how long it took to start.
    Turn Off / Turn On     Stops or starts the mod right away. Remembered for next time.
    Start Earlier / Later  Changes the order mods start in. Counts from the next level, or Restart Mods.
    Its settings           Mods with a settings page show it here. Settings are saved for you.
    Reset Settings         Puts the mod's settings back to their defaults.

BetterBlueprintLoader's own page has:
    Main Menu Label        The line at the bottom left of the main menu: how many mods are running.
    Main Menu Mods Button  The MODS button on the main menu.
    Restart Mods           Stops every mod and starts them again (also F12). Handy when making mods.

If the game crashes while a mod is starting, BetterBlueprintLoader turns that mod off and tells you on the main menu the next time. Turn it back on in the Mods tab when the mod is updated.

If the game updates, the Mods tab says so: if a level then crashes while loading, BetterBlueprintLoader needs an update too.

Turning a mod off stops it, but what it already changed in the game (like controls) can stay until the next level.

INSTALL
-------

1. Close the game, and fully close the Minecraft Launcher if you use it.

2. Open your Minecraft Dungeons II Paks folder.
    Steam: Right click the game in your library, then Manage > Browse local files, then open Dungeons\Content\Paks
    Minecraft Launcher: C:\XboxGames\Minecraft Dungeons II\Content\Dungeons\Content\Paks

3. Create a folder called ~mods inside the Paks folder if there is not one already.

4. If you have another mod loader, delete its folder from ~mods.

5. Extract this zip into ~mods, so the files end up in: Paks\~mods\BetterBlueprintLoader

UNINSTALL
---------

Delete the BetterBlueprintLoader folder from ~mods. Your other mods stop loading until a loader is installed again.

FOR MOD MAKERS
--------------

A mod is a ModActor class in /Game/Mods/YourMod. Its details and settings page come from /Game/Mods/YourMod/ModInfo, and it gets its settings through the BPI_ModSettings interface; BFL_ModSettings saves and reads its own values. With NeoRuneExtended: NeoRuneModTitle/Version/Author/Description in the project, [ModSetting.*] attributes on ModActor, and IModSettings.
