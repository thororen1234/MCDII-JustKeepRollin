JUST KEEP ROLLIN
================

Roll in mid-air!

You can roll while jumping or falling. It uses your normal roll key, so there's nothing to rebind.

REQUIREMENTS
------------

- BetterBlueprintLoader, which must also be installed
https://www.nexusmods.com/minecraftdungeons2/mods/95

INSTALL
-------

1. Close the game, and fully close the Minecraft Launcher if you use it.

2. Open your Minecraft Dungeons II Paks folder.
    Steam: Right click the game in your library, then Manage > Browse local files, then open Dungeons\Content\Paks
    Minecraft Launcher: C:\XboxGames\Minecraft Dungeons II\Content\Dungeons\Content\Paks

3. Create a folder called ~mods inside the Paks folder if there is not one already.

4. Extract this zip into ~mods, so the files end up in: Paks\~mods\JustKeepRollin

UNINSTALL
---------

Delete the JustKeepRollin folder from ~mods.
